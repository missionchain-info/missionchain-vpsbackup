# Web3 Copywriting — Mission Chain (EN canonical)

Write clean, glossary-correct, compliance-safe English source copy per format.

## Hard line (non-negotiable)
Never write returns / ROI / profit / "investment opportunity" language. SEED is a strategic-partner grant, jurisdiction USA — returns framing is a legal risk and the compliance gate will REDO it. Lead with verifiable facts, not financial upside.

## Per-format guidance
- **X post:** one idea, ≤280 chars, a concrete proof or question hook. **Thread:** premise → evidence (on-chain link) → implication → soft CTA (learn/join, not buy).
- **Telegram announcement:** concise, scannable, one action; pinnable.
- **YouTube/audio script:** intro hook (15s) → 2–3 teaching beats → recap → invite. Map to the 6 planned episodes (MC là gì / Tokenomics / MICE / Referral / +2).
- **TikTok/Shorts:** first line is a 3-second hook; <60s; sound-off legible; one idea. Usually repurposed from an episode.

## Locked Glossary terms (verbatim, so localizer keeps them untranslated)
`Mission Chain, MIC, MICE, MFP-NFT, NIRA, SOPHIA, DAO, USDT, Web3, SEED, Pre-Sale, Early Bird, Founding Partner, Direct Referral (F1), Indirect Referral (F2)`. Tagline verbatim: "Born of Faith. Built for People."

## Output
`_workspace/B_writer_{asset-id}.md` — frontmatter {channel, pillar, goal, format} + copy + source link for any on-chain claim. Mark unsourced figures `[UNVERIFIED — needs on-chain check]`.

## Voice
Faith-rooted, people-first, credible, calm. Invitation over pressure. Proof over adjectives.
