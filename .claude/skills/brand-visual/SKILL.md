# Brand Visual — Mission Chain

Turn approved copy into on-brand visual concepts + generation prompts (DALL·E 3 pipeline, per MC NFT/art standards).

## Method
1. Identify the single message the visual must reinforce (from the asset brief).
2. Prefer visualizing **real on-chain facts** (verified contracts, treasury, SEED 4-slot 20/20/10/50) over generic crypto stock imagery.
3. Write a precise generation prompt: subject, style, brand palette, composition, mood. Include tagline lockup where appropriate.
4. Keep logo usage, typography, and palette consistent across assets.

## Guardrails
- **Faith-authentic, never exploitative** — religious imagery with respect and restraint, never as a sales lever or prosperity bait. Borderline → escalate to brand-guardian/compliance.
- No motifs implying financial gain ("to the moon", up-only charts, money rain) — the compliance gate will reject them.

## Output
`_workspace/B_visual_{asset-id}.md` — concept description + generation prompt(s). Note source if repurposed.
