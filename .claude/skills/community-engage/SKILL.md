# Community Engage — Mission Chain Distribution & Engagement

Distribute PASS'd assets and bring community signal back. Never publish an ungated asset.

## Publishing per channel
- **X/Twitter:** thread structure (premise → evidence → implication → soft invite); pin milestone threads.
- **Telegram:** concise + pinnable; coordinate NIRA (replies in groups only when @tagged/replied; warm, non-spammy). Use existing inactive-member ping flow, not a new bot.
- **YouTube:** episode + description with official links; enable captions/subtitles (multilingual).
- **TikTok:** caption + hashtags; organic only; sound-off legible.

## Anti-impersonation (a security control in crypto)
- Regularly pin/repeat the **official channels & domains** so users can verify the real Mission Chain.
- Watch for clone/scam accounts; log, alert the Owner, and post an official-channels reminder.

## Sentiment capture
Record recurring questions, confusion, reactions, and scam attempts for analytics + strategist.

## Output
`_workspace/D_community_publish-log.md` ({asset-id, channel, time, link}) + `_workspace/D_community_sentiment.md`.

## Gate discipline
Distribute only assets carrying PASS from BOTH compliance-reviewer and brand-guardian. Route financial-advice questions to disclaimers, not opinions.
