# Short-Video — Mission Chain (TikTok / Shorts, 9:16)

Design vertical short-form treatments, usually **repurposed** from a YouTube/audio episode into 4–6 cuts.

## Method
1. Pick one idea per clip (never cram a whole episode into one short).
2. **Hook in the first frame / first line** (3-second rule) — a question, a surprising on-chain fact, or a bold claim of *fact* (never of returns).
3. Write a shot list: {scene, on-screen text/caption, voiceover/audio, duration} — total <60s.
4. Captions legible sound-off; brand palette + logo bug; end with a soft invite (learn/join), not "buy".

## TikTok compliance (stricter — read before producing)
- **Organic only.** TikTok bans paid crypto promotion; MC does not run paid crypto ads.
- TikTok aggressively removes financial-advice / returns / "get rich" content → be extra-conservative; frame as education & transparency.
- Everything still passes the compliance + brand gate before publishing.

## Repurposing
From one episode, cut: a hook moment, a single teaching beat, an on-chain proof visual, a mission/faith beat. Note the source episode + timestamp.
