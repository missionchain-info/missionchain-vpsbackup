# Social Analytics — Mission Chain

Close the loop: measure → decide what to keep/cut/amplify → propose next-cycle changes.

## Method
1. Pull per-channel metrics vs the campaign KPIs (reach, engagement, community growth, sentiment). Prefer the KPI the strategist named; ignore vanity metrics that won't change a decision.
2. Classify each asset/pillar/channel: **keep** (working), **cut** (not working), **amplify** (over-performing → do more/repurpose).
3. Feed the **evolution loop:** recurring wins/losses → propose a concrete change (calendar reweight, new/edited skill, agent tweak). Route via strategist + record in the CLAUDE.md change log.

## Output
`_workspace/E_analytics_insights.md` — per-channel keep/cut/amplify + proposed next-cycle adjustments.

## Honesty
If a channel's metrics are unavailable, report the gap — never infer performance from nothing.
